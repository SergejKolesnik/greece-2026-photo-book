# Продовження проєкту

Читайте PROJECT_CONTEXT.md, PROJECT_STATUS.md і DECISIONS.md перед змінами.
Codex координує; Hermes можна залучати через встановлений CLI для окремих перевірок без паралельного редагування тих самих файлів.
Публікуйте лише погоджені S01–S69; звіряйте SELECTION_MANIFEST.csv. Не включайте архів, приватні фото, секрети чи журнали. Не змінюйте оригінали.
Єдине джерело редакційної версії — docs/content.json. Підтримуйте однаковий зміст сайту й PDF, 28 сторінок і 2 сторінки порома.
GitHub Pages публікує main:/docs. Зберігайте історію, не робіть force push. Перед push перевіряйте git diff і список файлів.
Перевіряйте мобільний екран, переглядач, JPEG fallback, фільтри й кластер карти, опублікований HTTPS URL. Не видавайте емуляцію за перевірку фізичного Android.
