# Продовження проєкту

Читайте PROJECT_CONTEXT.md, PROJECT_STATUS.md і DECISIONS.md перед змінами.
Codex координує; Hermes можна залучати через встановлений CLI для окремих перевірок без паралельного редагування тих самих файлів.
Публікуйте лише погоджені S01–S69; звіряйте SELECTION_MANIFEST.csv. Не включайте архів, приватні фото, секрети чи журнали. Не змінюйте оригінали.
Єдине джерело редакційної версії — docs/content.json. Підтримуйте однаковий зміст сайту й PDF, 28 сторінок і 2 сторінки порома.
GitHub Pages публікує main:/docs. Зберігайте історію, не робіть force push. Перед push перевіряйте git diff і список файлів.
Не повертайте автоматичну стрічку або текстові сторінки без фото. Зберігайте 28 макетних фотосторінок, 69 унікальних кадрів і відсутність вигаданих дат/локацій. Читайте EDITORIAL_RECONCILIATION.md щодо суперечностей файлів Hermes. Повторні візити мають бути редакційно пояснені.
Збірка: python scripts/build_site.py; python scripts/build_pdf.py. Перевірка: python scripts/verify_journal.py; після публікації додайте --url https://sergejkolesnik.github.io/greece-2026-photo-book/ . PDF потребує Pillow/reportlab і шрифтів Segoe UI/Georgia; JOURNAL_FONT_DIR задає їхній каталог.
Перевіряйте мобільний екран, переглядач, JPEG fallback, усі дев'ять SVG-маркерів, однаковий масштаб контуру/позначок і опублікований HTTPS URL. Не видавайте емуляцію за перевірку фізичного Android.
