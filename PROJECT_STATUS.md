## Публікація

GitHub Pages налаштований на `main:/docs`. Причина попередньої розбіжності: нові виправлення ще не були злиті в `main`; публічний сайт і старий PDF відповідали попередньому маніфесту, а не новій редакції. Створити PR можна після перевірки гілки; злиття та публікація очікують погодження власника. Після публікації слід виконати `scripts/verify_journal.py --url https://sergejkolesnik.github.io/greece-2026-photo-book/`, перевірити GitHub Pages і перебудувати фінальний PDF.

Фізичний Android через мобільну мережу тут не випробувано; перевірено браузерний мобільний макет і мобільні завантаження локальної збірки.
