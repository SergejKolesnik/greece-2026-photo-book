# Греція 2026

Авторський фотожурнал для друзів про подорож двох людей 8–17 жовтня 2026 року: Афіни, переліт на Мілос, острів, пляжі, селища, прощання й пором.

Канонічна основа — погоджений план Hermes на 28 фотосторінок і 69 фото. Редакція зберігає ці 28 сторінок і додає сторінку про Венеру Мілоську та інфографіку, разом 30 PDF-сторінок. Поточна підготовлена версія — `GR26-20261019-V05`. У журналі 69 особистих фото; чотири слабші/повторні кадри замінені кадрами C01–C04, схваленими власником. Згода Оксани на C01, C03 та C04 підтверджена. Джерела й заміни пояснено в `EDITORIAL_RECONCILIATION.md` і `PHOTO_ADDITIONS.csv`.

Єдине джерело змісту для сайту й PDF — `docs/content.json`. `scripts/build_site.py` генерує статичну розмітку; `scripts/build_pdf.py` генерує PDF. `scripts/verify_journal.py` перевіряє маніфест, зображення, хронологію, карту й, за потреби, публічний сайт. `PAGE_AUDIT.csv` охоплює всі 30 сторінок. Обкладинка S12 походить з особистого архіву (доказ у `COVER_ORIGIN.md`); ілюстрація Венери — окреме музейне зображення CC0.

GitHub Pages публікує `main:/docs`. Поточна публічна адреса: https://sergejkolesnik.github.io/greece-2026-photo-book/ . Гілка підготовки карти V05 — `editorial/map-from-travel-screenshot`; статичну SVG-карту доповнено трьома інтерактивними групами A–C із червоних міток наданого скриншота. Зміни очікують редакторського погодження та публікації.
